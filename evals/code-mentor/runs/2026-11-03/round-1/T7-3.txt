## Paso 1: `DATABASE_URL`

**El problema.** Tu app corre en un sitio y tu base de datos en otro: Neon es Postgres alojado en sus servidores. Para hablar con ella, la app necesita saber dónde está y con qué credenciales entrar. Todo eso cabe en un solo texto, la **connection string** (cadena de conexión). Por convención se guarda en una variable llamada `DATABASE_URL`.

**Sus partes**, con el ejemplo de la documentación de Neon:

```
postgresql://alex:****@ep-cool-darkness-a1b2c3d4-pooler.us-east-2.aws.neon.tech/dbname?sslmode=require&channel_binding=require
```

| Parte | Valor | Qué es |
|---|---|---|
| Protocolo | `postgresql://` | El "idioma" de la conexión |
| Rol | `alex` | El usuario de la base de datos |
| Contraseña | `AbC123dEf` | **El secreto** |
| Host | `ep-cool-darkness-a1b2c3d4-pooler.us-east-2.aws.neon.tech` | El servidor. `-pooler` indica conexión agrupada: muchos clientes comparten pocas conexiones reales |
| Base de datos | `dbname` | Un mismo servidor puede tener varias |
| Parámetros | `sslmode=require&channel_binding=require` | Opciones de conexión. Neon exige SSL (conexión cifrada), así que no los borres |

Se lee así: "conéctate con Postgres, como `alex` con esta contraseña, a este servidor, a la base `dbname`, y con cifrado".

**Por qué no va en el código.** Compara las dos opciones:

```ts
// ❌ En el código: la contraseña entra en cada commit
const url = 'postgresql://alex:****@...'

// ✅ En el código solo está el nombre de la variable
const url = process.env.DATABASE_URL
```

Con la primera, si subes el repo a GitHub, cualquiera con acceso lee la contraseña y puede borrar tus datos. Borrarla después no basta, porque sigue en el historial de git. Habría que cambiar la contraseña.

La solución son dos archivos:

```
.env          → valor real      → fuera de git (ya está en .gitignore)
.env.example  → valor falso     → en git: indica qué variables hacen falta
```

**Qué harás cuando tengas acceso a Neon** (no lo he podido probar):
1. Pulsa **New Project**, pon nombre y región (la más cercana a donde corra tu app) y pulsa **Create project**.
2. Pulsa **Connect**. Se abre un panel que monta la cadena. Deja los valores por defecto, incluido el agrupado (pooled).
3. Copia la cadena en `.env`: `DATABASE_URL=postgresql://...`
4. Nunca la pegues en un chat, tampoco aquí.
