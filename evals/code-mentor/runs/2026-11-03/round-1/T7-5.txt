## Paso 2: conectar Hono con Neon

**El problema.** Ya sabes qué es `DATABASE_URL`, pero ningún código la usa. Antes de crear tablas, conviene probar solo la conexión. Si mezclas ambas cosas y algo falla, no sabrás si el fallo está en la conexión o en tu SQL.

**La idea.** Una ruta temporal, `GET /db-check`, lanza la query más simple posible:

```sql
SELECT 1 AS ok
```

No lee ninguna tabla: pide a Postgres que devuelva una fila con una columna `ok` que vale `1`. `AS` le pone nombre a la columna. Si recibes esa fila, la conexión funciona.

**Las 3 piezas nuevas**

**1. Leer la variable con `env()`**

```ts
import { env } from 'hono/adapter'

app.get('/ejemplo', (c) => {
  const { API_KEY } = env<{ API_KEY: string }>(c)
  // ...
})
```

`c` es el contexto de la petición en Hono. `<{ API_KEY: string }>` le dice a TypeScript qué variable esperas.

La alternativa obvia es `process.env`, pero depende de dónde corra la app, y tu proyecto aún no lo define. `env()` funciona en Node, Bun, Cloudflare Workers y otros.

**2. Crear el cliente con `neon()`**

```ts
import { neon } from '@neondatabase/serverless'

const sql = neon(url)
```

`neon()` no devuelve datos, sino una función, `sql`, con la que lanzas queries. Cada query viaja como una petición HTTP a Neon, así que no tienes que abrir ni cerrar conexiones.

**3. Lanzar la query**

```ts
const filas = await sql`SELECT 'hola' AS saludo`
// filas → [ { saludo: 'hola' } ]
// filas[0].saludo → 'hola'
```

Fíjate en tres cosas:
- **Comillas invertidas, sin paréntesis:** es una *tagged template*. Más adelante, un valor escrito como `${id}` no se pega dentro del texto SQL, y eso protege contra la inyección SQL.
- **`await`:** la respuesta viene por la red y tarda. Sin `await` tendrías una promesa, no las filas. La función de la ruta debe ser `async`.
- **El resultado es siempre un array de filas:** cada fila es un objeto cuyas claves son los nombres de columna. Aunque haya una sola fila, necesitas `[0]`.

**Recorrido con valores reales:**

```
GET /db-check
  │
  ├─ env(c)               → DATABASE_URL = 'postgresql://...'
  ├─ neon(url)            → sql (función)
  ├─ sql`SELECT 1 AS ok`  → viaja a Neon por HTTP
  ├─ filas                → [ { ok: 1 } ]
  ├─ filas[0].ok          → 1
  └─ respuesta            → {"ok":1}
```

**Seguridad:** este código corre en el servidor, nunca en el navegador. No devuelvas `DATABASE_URL` en una respuesta, porque contiene la contraseña.
