### Cómo se lee una tabla

Sigamos con los votos, ahora con dos filas:

```
 nombre | total
--------+-------
 gatos  |     3
 perros |     5
```

Para leer se usa `SELECT`, y esta es su forma general:

```sql
SELECT columna FROM tabla WHERE otra_columna = 'valor'
```

- **`SELECT columna`:** qué dato quieres.
- **`FROM tabla`:** de qué tabla.
- **`WHERE ...`:** qué filas quieres. Sin esto, recibes todas.

Sigamos dos consultas con esos datos:

```
SELECT total FROM votos                        → 3 y 5 (todas las filas)
SELECT total FROM votos WHERE nombre = 'gatos' → 3     (solo gatos)
```

El `WHERE` importa aunque ahora solo tengas la fila `home`: si mañana añades otro contador, seguirás leyendo el correcto.

### Qué recibe tu código

El resultado siempre llega como una **lista de filas**, aunque solo haya una. Cada fila es un objeto cuyas claves son los nombres de las columnas:

```
sql`...WHERE nombre = 'gatos'`  →  rows = [ { total: 3 } ]
                                   rows[0]        = { total: 3 }
                                   rows[0].total  = 3
```

Es lo mismo que ya hiciste en `ping()` con `rows[0].ok`.
