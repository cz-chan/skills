## Mi parte: las rutas
Sustituye `// TODO: /api/likes` en `src/index.ts` y añade el `import` arriba:

```ts
import { addLike, getLikeCount } from './likes'

// Al cargar la página: solo lee el contador
app.get('/api/likes', async (c) => {
  return c.json({ count: await getLikeCount() })
})

// Al pulsar el botón: guarda el like y devuelve el contador nuevo
app.post('/api/likes', async (c) => {
  await addLike()
  return c.json({ count: await getLikeCount() })
})
```

**Por qué hay dos rutas:** leer y modificar son acciones distintas. `GET` solo lee, así que recargar la página no suma likes. `POST` cambia datos, y solo se llama al hacer clic.

Por ejemplo, si la base de datos ya tiene 3 likes:

| Acción | Petición | Qué hace | Respuesta |
|---|---|---|---|
| Abres la página | `GET` | lee | `{ "count": 3 }` |
| Haces clic | `POST` | guarda un like y lee | `{ "count": 4 }` |
| Recargas | `GET` | lee | `{ "count": 4 }` |
