## Paso 1: crear la base de datos y guardar cómo conectarse

### Por qué hace falta una base de datos
Podríamos guardar el contador en una variable del servidor:

```ts
let likes = 0
```

Así se comportaría:

| Acción | Valor de `likes` |
|---|---|
| Arrancas el servidor | 0 |
| Clic | 1 |
| Clic | 2 |
| Recargas la página | 2 (el servidor sigue encendido) |
| Reinicias el servidor | **0: likes perdidos** |

La variable vive en la memoria del proceso y muere con él. Una **base de datos** es un programa aparte que guarda los datos en disco, así que sobreviven a los reinicios de tu servidor.

**Postgres** es ese programa, y **Neon** te lo da ya instalado en la nube. Tu app se conecta a él por internet:

```
[Tu servidor Hono] ──internet──▶ [Postgres en Neon] ──▶ disco
   se puede reiniciar                 los datos siguen aquí
```

### Qué es una cadena de conexión
Es un texto con todo lo que tu app necesita para entrar en la base de datos. Este ejemplo es inventado:

```
postgresql://ana:****@ep-demo-123.eu-central-1.aws.neon.tech/neondb?sslmode=require
             │   │      │                                      │      │
           usuario      servidor                       base de datos  opciones
                 contraseña                                         (conexión cifrada)
```

Incluye tu contraseña, así que quien la tenga puede leer y borrar tus datos. Por eso va en `.env`, un archivo con secretos que se queda en tu máquina si le dices a git que lo ignore.

### Qué tienes que hacer
1. **Protege el secreto primero:** añade esta línea a `.gitignore`. Así el archivo no acabará en git por accidente, porque ahora mismo no está ignorado.
   ```
   .env
   ```
2. **Crea el proyecto:** entra en [neon.com](https://neon.com), regístrate si hace falta y crea un proyecto. Elige la región más cercana a ti para que las consultas tarden menos.
3. **Copia la cadena de conexión:** en el panel del proyecto, busca el botón **Connect**. Lo cito de memoria y no he podido comprobar la web de Neon, así que si no lo ves, dime qué te aparece.
4. **Crea el archivo `.env`:** ponlo en la raíz del proyecto, junto a `package.json`, con tu cadena real:
   ```
   DATABASE_URL="postgresql://..."
   ```

No pegues la cadena en este chat ni le quites `?sslmode=require`: esa opción es la que pide la conexión cifrada.

### Cómo sabremos que está bien
Cuando me escribas **"listo"**, compruebo dos cosas sin mostrar el valor: que git ignora `.env` y que `DATABASE_URL` existe.

En el paso 2 conectamos Hono a Neon y hacemos la primera consulta. Después ya te tocará diseñar tu tabla.
