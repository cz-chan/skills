## Cómo se define una columna

`CREATE TABLE` crea una tabla vacía y define sus columnas. Cada columna lleva un nombre, un tipo y, si hace falta, reglas:

```sql
CREATE TABLE nombre_tabla (
  columna1 tipo reglas,
  columna2 tipo reglas
);
```

Estas son las piezas para cada columna:

| Columna | Tipo | Reglas | Por qué |
|---|---|---|---|
| `id` | `bigint` | `GENERATED ALWAYS AS IDENTITY`, `PRIMARY KEY` | La base de datos genera 1, 2, 3… y no se repite ninguno. `bigint` admite números muy grandes. |
| `post_id` | `text` | `NOT NULL` | Guarda textos como `hola-mundo`. `NOT NULL` impide un like sin post. |
| `created_at` | `timestamptz` | `NOT NULL`, `DEFAULT now()` | Es un instante exacto, con zona horaria. `DEFAULT` lo rellena si no le das valor. |

## Qué pasa al insertar

| Insertas | Resultado |
|---|---|
| `post_id = 'hola-mundo'` | Fila con `id = 1`, `post_id = 'hola-mundo'` y `created_at` = la hora actual |
| `post_id = 'hola-mundo'` otra vez | Fila nueva con `id = 2`: es otro like del mismo post |
| Sin `post_id` | **Error** por `NOT NULL`: no se guarda nada |

Por eso, en el paso 4, tu insert solo tendrá que enviar `post_id`.
