## Mismo patrón, otro problema

Imagina una tabla de libros, descrita igual que la nuestra:

| Columna | Tipo | Reglas |
|---|---|---|
| `isbn` | `text` | `PRIMARY KEY` |
| `titulo` | `text` | `NOT NULL` |
| `paginas` | `integer` | `NOT NULL`, `DEFAULT 0` |

Cada fila de esa descripción se convierte en una línea de SQL. Solo hay que leerla de izquierda a derecha:

```sql
CREATE TABLE libros (
  isbn text PRIMARY KEY,
  titulo text NOT NULL,
  paginas integer NOT NULL DEFAULT 0
);
```

Fíjate en dos cosas:
- **Varias reglas:** van seguidas, separadas por espacios, como en `NOT NULL DEFAULT 0`.
- **Las comas:** separan columnas, así que la última columna no lleva coma.

Con esta tabla, los datos se comportarían así:

| Insertas | Resultado |
|---|---|
| `isbn = '978'`, `titulo = 'Dune'` | Fila guardada con `paginas = 0`, por el `DEFAULT` |
| `isbn = '979'`, sin `titulo` | **Error** por `NOT NULL` |
