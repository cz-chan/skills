## Paso 1: la tabla donde vive el contador

**El problema:** si guardas los likes en una variable de JavaScript, como `let total = 7`, se pierden al reiniciar el servidor y vuelves a 0. Una base de datos los guarda en disco, fuera de tu app.

### Las piezas

Una **tabla** es como una hoja de cálculo. Cada **columna** define un dato y su tipo, y cada **fila** es un registro:

```
tabla: likes
┌────┬───────┐
│ id │ total │  ← columnas
├────┼───────┤
│  1 │     0 │  ← una fila
└────┴───────┘
```

Solo necesitamos una fila, porque hay un único contador global.

| Pieza | Qué hace | Qué pasaría sin ella |
|---|---|---|
| `INTEGER` | Solo admite números enteros | Podría entrar un `'hola'` en vez de un número |
| `PRIMARY KEY` | Identifica cada fila: no admite repetidos ni vacíos | Podría haber dos filas con `id = 1` y dos contadores |
| `NOT NULL` | Prohíbe `NULL`, que significa "sin valor" | Ver el ejemplo de abajo |
| `DEFAULT 0` | Pone 0 si no indicas un valor | Si no indicas `total`, queda `NULL`, o da error si la columna es `NOT NULL` |

### Por qué importa `NOT NULL`

En SQL, cualquier suma con `NULL` da `NULL`:

```
total = 5     →  5 + 1    = 6     bien
total = NULL  →  NULL + 1 = NULL  el contador nunca sube, y sin error
```

### Por qué hace falta una fila inicial

`CREATE TABLE` solo crea la estructura, y la tabla empieza vacía. En el paso 2, cada clic hará "suma 1 a la fila con `id = 1`". Así cambia la tabla:

```
Orden                       Tabla después       Resultado
1. CREATE TABLE             (vacía)             tabla creada
2. Clic sin fila inicial    (vacía)             0 filas cambiadas, sin error: like perdido
3. INSERT con id = 1        id=1, total=0       1 fila creada
4. Clic                     id=1, total=1       1 fila cambiada
5. Clic                     id=1, total=2       1 fila cambiada
6. INSERT con id = 1 otra   id=1, total=2       ERROR: id repetido
```

La fila 2 es el fallo peligroso, porque nada te avisa. La fila 6 muestra a `PRIMARY KEY` protegiéndote de un segundo contador.

### La sintaxis

```sql
CREATE TABLE nombre_tabla (
  columna_a TIPO RESTRICCIONES,
  columna_b TIPO RESTRICCIONES
);

INSERT INTO nombre_tabla (columna_a, columna_b) VALUES (valor_a, valor_b);
```

Las columnas van separadas por comas, sin coma tras la última, y cada sentencia termina en `;`.
