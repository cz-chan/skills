## Por qué hace falta una base de datos

Primero, la opción obvia: guardar el contador en una variable del servidor.

```ts
let likes = 0
```

Mira qué pasa con valores reales:

| Acción | `likes` |
|---|---|
| 3 clics | 3 |
| Recargas la página | 3 (el servidor sigue encendido) |
| El servidor se reinicia | **0**: se pierde todo |

La variable vive en la memoria (RAM), que se borra al apagar el programa. Una **base de datos** es otro programa, y guarda los datos en disco. **Neon** nos da una base de datos **Postgres** en la nube, así que tu app puede reiniciarse sin perder nada.

## Cómo se organizan los datos

- **Tabla:** datos con forma de cuadrícula, como una hoja de cálculo.
- **Columna:** un dato que tiene cada fila, con un tipo fijo (número, fecha, texto).
- **Fila:** un elemento guardado.
- **Esquema:** la definición de tus tablas y columnas. No son los datos, sino su forma.
- **Query:** una orden en **SQL**, el lenguaje con el que le hablas a la base de datos.

## Cómo vamos a contar los likes

He elegido **una fila por cada like**: el contador es el número de filas.

```text
Inicio    tabla likes: (vacía)            contador = 0
Clic 1    añade una fila: [fila 1]        contador = 1
Clic 2    añade otra:     [fila 1][fila 2] contador = 2
Recarga   no añade nada, solo cuenta      contador = 2
Reinicio  las filas siguen en Neon        contador = 2
```

La alternativa es una sola fila con una columna numérica que vas aumentando. También vale, pero antes tendrías que crear esa fila inicial. Añadir filas y contarlas es más sencillo para tus primeras queries, y además guarda cuándo ocurrió cada like si añades esa columna.

Tus piezas serán estas:

| Pieza | Qué hace | Cuándo se usa |
|---|---|---|
| Esquema | Crea la tabla | Una vez |
| Query 1 | Añade una fila | En cada clic |
| Query 2 | Cuenta las filas | En cada clic y al cargar la página |

## Paso 1: crear el proyecto en Neon

Vamos a probar SQL directamente en Neon, sin tocar todavía la app, para que veas cada resultado al momento. Todavía no necesitas tu clave de conexión.

1. Entra en [neon.com](https://neon.com) y crea una cuenta.
2. Crea un proyecto llamado `c12z-demo`, en la región más cercana a ti.
3. Abre el **SQL Editor** en el menú del proyecto. Los nombres de la web pueden variar un poco.
4. Ejecuta esta query:

```sql
SELECT 1 + 1;
```

`SELECT` significa "devuélveme este valor". Aquí no lee ninguna tabla: solo le pide a Postgres que calcule algo y te lo muestre. **Deberías ver una fila con el valor `2`**, lo que prueba que tu base de datos responde.
