## Paso 1: conectar la app con Neon

Ahora un like no tiene dónde guardarse. Si solo estuviera en la memoria del navegador o del servidor, se perdería al recargar la página o al reiniciar el servidor.

**Postgres** es una base de datos: un programa que guarda datos en disco y los devuelve cuando se los pides con SQL. **Neon** te da un Postgres en la nube, así que no tienes que instalar nada.

```
Navegador ──▶ Tu servidor Hono ──▶ Neon (Postgres)
público        privado              datos guardados
               lee .env
```

### Qué es la connection string
La **connection string** es una URL con todo lo necesario para conectarse a la base de datos. Por ejemplo, con valores inventados:

```
postgresql://neondb_owner:****@ep-rio-123.eu-central-1.aws.neon.tech/neondb?sslmode=require
```

| Parte | Valor | Significado |
|---|---|---|
| Usuario | `neondb_owner` | Quién se conecta |
| Contraseña | `abc123` | **El secreto** |
| Host | `ep-rio-123...neon.tech` | Dónde está el servidor |
| Base de datos | `neondb` | A qué base de datos entras |
| Opción | `sslmode=require` | Exige una conexión cifrada |

Con esta URL, cualquiera podría leer o borrar tus datos. Por eso va en `.env`, un archivo que Git ignora y que solo lee el servidor. Tampoco la pegues en este chat.

### Qué tienes que hacer

**1. Protege `.env` antes de crearlo.** Ahora mismo Git no lo ignora, y tampoco `node_modules/`, la carpeta enorme de dependencias que se puede regenerar:

```sh
printf '.env\nnode_modules/\n' >> .gitignore
git check-ignore .env node_modules
```

La segunda línea debe mostrar `.env` y `node_modules`.

**2. Crea el proyecto en [Neon](https://neon.com).** Regístrate, crea un proyecto y elige la región más cercana. Deja el resto como esté. No he podido abrir la documentación de Neon, así que los botones pueden tener otro nombre.

**3. Copia la connection string.** Suele aparecer al pulsar **Connect** en el panel del proyecto. Copia solo la URL que empieza por `postgresql://`.

**4. Crea `.env` en la raíz del proyecto** con tu editor y pega esto con tu URL:

```
DATABASE_URL="postgresql://..."
```

`DATABASE_URL` es una **variable de entorno**: un valor que el programa lee al arrancar, sin que esté escrito en el código.

**5. Instala las dependencias.** Instala las versiones de `package.json` y crea `node_modules/` y `package-lock.json`:

```sh
npm install
```

**6. Comprueba la conexión:**

```sh
node --env-file=.env --input-type=module -e 'import { neon } from "@neondatabase/serverless"; const sql = neon(process.env.DATABASE_URL); console.log(await sql`SELECT 1 AS ok`)'
```

Este comando hace lo siguiente:
- **`--env-file=.env`:** carga tu `DATABASE_URL`. Tu Node es v24, así que admite esta opción.
- **`neon(...)`:** prepara el cliente que enviará las queries a Neon.
- **`SELECT 1 AS ok`:** es tu primera query. No lee ninguna tabla: le pide a Postgres que devuelva el valor `1` en una columna llamada `ok`.

Deberías ver esto:

```
[ { ok: 1 } ]
```

Es una lista con una fila, y esa fila tiene la columna `ok` con valor `1`. Todas las queries de este proyecto devolverán filas en este formato. Aún no he podido probar el comando porque necesita tu base de datos.
