| 2. Llega al servidor | `app.post('/api/likes', ...)` | Hono recibe la petición y llama a `addLike()` |

## Las partes nuevas
- **`const page`:** guarda el HTML de la página como texto. Las comillas invertidas `` ` `` permiten escribirlo en varias líneas.
- **`<script>`:** este código no corre en el servidor. Hono lo envía como texto y lo ejecuta el navegador.
- **`app.get('/', (c) => c.html(page))`:** cuando alguien abre `/`, envía esa página. Sustituye al antiguo `c.text('c12z')`.
- **`c`:** es el contexto de Hono, el objeto con el que la ruta lee la petición y crea la respuesta.
- **`await`:** espera a que Neon responda antes de seguir. Sin él, enviarías una promesa sin resolver en lugar del número.
- **`callLikes(method)`:** es una sola función para los dos casos, porque solo cambia el método. Así no repetimos el mismo código para `GET` y `POST`.
- **`res.ok`:** `fetch` no falla cuando el servidor responde con un error como el 500, así que hay que comprobarlo a mano. Si no, intentaríamos mostrar un total que no existe.
- **`button.disabled = true`:** bloquea el botón mientras espera la respuesta, para que un doble clic rápido no envíe dos likes.
