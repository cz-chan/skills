## Paso 4: la ruta y el botón

Este código es mío: **tú lo pegas en `src/index.ts`**. Lo importante para aprender bases de datos es ver cómo llega un clic hasta tus queries. **Sin ejecutar**, porque aquí faltan `hono` y Neon.

### Cómo viaja un clic

Con `total = 7` en la base de datos:

```
1. Clic en el botón        fetch envía POST /api/likes
2. Ruta POST               llama a addLike()
3. addLike() (tu código)   UPDATE ... RETURNING total
4. Neon                    pasa total de 7 a 8 y devuelve [ { total: 8 } ]
5. addLike()               devuelve 8
6. Ruta POST               responde { "total": 8 }
7. Botón                   muestra 8
```

Al recargar la página, el navegador envía `GET /api/likes`. Esa ruta llama a `getLikes()`, que solo lee, y muestra 8 otra vez.

**Por qué dos métodos en la misma URL:** `GET` es para pedir datos, y `POST` para enviar una acción que cambia algo. Si `GET` sumara likes, cada recarga añadiría uno.

### Código

**1. Arriba, debajo del import de Hono:**

```ts
// Conecta con tus funciones de src/db.ts

```

**2. Sustituye la línea `app.get('/', (c) => c.text('c12z'))` por esto:**

```ts
const page = `<!doctype html>
<html>
  <body>
    <h1>c12z</h1>
    <button id="like">❤️ <span id="total">...</span></button>
    <script>
      const button = document.getElementById('like')
      const total = document.getElementById('total')

      // Llama a /api/likes: GET lee, POST suma
      async function request(method) {
        const res = await fetch('/api/likes', { method })
        if (!res.ok) {
          total.textContent = 'error'
          return
        }
        const data = await res.json()
        total.textContent = data.total
      }

      // Al cargar la página: solo lee
      request('GET')

      // Al hacer clic: suma un like
      button.onclick = async () => {
        button.disabled = true
        try {
          await request('POST')
        } finally {
          button.disabled = false
        }
      }
    </script>
  </body>
</html>`

app.get('/', (c) => c.html(page))
```

### Qué hace cada parte

| Parte | Qué hace | Por qué |
|---|---|---|
| `c.html(page)` | Envía la página al navegador | Sustituye al texto `c12z`, que ahora es el título |
| `<script>` | Corre en el **navegador** | No puede tener la contraseña, así que le pide los datos a tu API |
| `c.json({ total })` | Responde con `{ "total": 8 }` | El botón lee `data.total` de esa respuesta |
| `if (!res.ok)` | Muestra `error` si la ruta falla | Si no, el contador se quedaría sin cambiar y sin avisar |
| `button.disabled` | Bloquea el botón mientras espera | Evita que el mismo navegador envíe clics solapados y que una respuesta vieja pise a otra |

Esto completa la separación de la que hablábamos: el navegador habla con tu API, y solo la API habla con Neon.

### Límites que debes conocer

- **Sin límite de likes:** cualquiera puede hacer clic o enviar `POST` todas las veces que quiera. Es lo que elegiste con el contador global, y para aprender está bien.
