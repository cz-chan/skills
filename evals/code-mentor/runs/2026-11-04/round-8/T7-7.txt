## Paso 3: conectar la app a Neon

**El problema:** tus queries son texto en un archivo. La app aún no puede enviarlas a ninguna base de datos, y para eso necesita dos cosas: la dirección con su contraseña, y un programa que envíe las queries.

### 1. La dirección: la cadena de conexión

Neon te dará una URL con esta forma (valores inventados):

```
postgresql://alex:****@ep-cool-123.us-east-2.aws.neon.tech/neondb?sslmode=require
             └┬─┘ └───┬───┘ └───────────────┬──────────────┘ └──┬─┘ └──────┬───────┘
            usuario contraseña            servidor            base     opción: conexión
                                                              de datos  cifrada
```

Contiene la contraseña, así que **no puede ir en el código**: si haces push, quien vea el repo entra en tu base de datos. Por eso se guarda aparte, en un archivo `.env`, y el código la lee de una variable de entorno:

```
.env (fuera de git)                →  DATABASE_URL=postgresql://alex:...
código                             →  process.env.DATABASE_URL
valor que recibe el código         →  "postgresql://alex:..."
valor si falta la variable         →  undefined
```

**Haz esto antes de seguir:** tu `.gitignore` todavía no incluye `.env`. Añádelo ahora para no subir la contraseña por accidente cuando tengas Neon.

### 2. El programa: el driver

Un **driver** es la librería que lleva tus queries a la base de datos. Ya tienes `@neondatabase/serverless` en `package.json`. Su función `neon()` envía cada query como una petición HTTP. Así se usa, con otra query distinta a las tuyas:

```ts
import { neon } from '@neondatabase/serverless'

const sql = neon(process.env.DATABASE_URL)
const rows = await sql`SELECT * FROM posts WHERE id = 1`
```

- **``sql`...` ``:** la query va entre comillas invertidas, sin paréntesis.
- **`await`:** la respuesta viene por la red y tarda, así que hay que esperarla.

### 3. Qué devuelve

Siempre devuelve un **array de filas**, aunque solo haya una. Siguiendo un clic con `total = 7`:

```
Código o paso          Valor
UPDATE ... RETURNING   la base de datos pasa total de 7 a 8
rows                   [ { total: 8 } ]    array con una fila
rows[0]                { total: 8 }        la primera fila
rows[0].total          8                   el número que quieres
```

Aquí se ve otra vez por qué hacía falta la fila inicial del paso 1: sin ella, `rows` sería `[]`, `rows[0]` sería `undefined` y `rows[0].total` lanzaría un error.

### Cómo encaja

```
[Botón] ──▶ [/api/likes] ──▶ addLike() ──▶ sql`UPDATE...` ──HTTP──▶ [Neon]
              paso 4           TÚ, ahora       driver
```

La ruta del paso 4 solo llamará a tus funciones, sin escribir SQL. Así todo el SQL queda en un único archivo.
