## Cómo se decide cada columna
Para cada columna, responde tres preguntas en este orden. Cada respuesta te da una parte de la línea:

## Ejemplo con otra tabla: libros
| Columna | ¿Qué guarda? | ¿Identifica la fila? | ¿Puede faltar? | Línea |
|---|---|---|---|---|
| `isbn` | texto, `978-1` | sí | no | `isbn text PRIMARY KEY` |
| `titulo` | texto, `Dune` | no | no | `titulo text NOT NULL` |
| `paginas` | número, `412` | no | si falta, 0 | `paginas integer DEFAULT 0` |

Juntas quedan así:

```sql
CREATE TABLE libros (
  isbn     text PRIMARY KEY,
  titulo   text NOT NULL,
  paginas  integer DEFAULT 0
);
```

Y esto ocurre al insertar:

| Insertas | Resultado |
|---|---|
| `isbn = '978-1'`, `titulo = 'Dune'` | se guarda con `paginas = 0`, el valor automático |
| `isbn = '978-1'` otra vez, `titulo = 'Otro'` | error: el `isbn` ya existe y `PRIMARY KEY` no deja repetirlo |
| `isbn = '978-2'`, sin `titulo` | error: `NOT NULL` exige un título |

Cada regla responde a una de esas preguntas: por eso la línea sale sola al contestarlas.
