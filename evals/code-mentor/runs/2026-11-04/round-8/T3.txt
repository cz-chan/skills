**El cuadro completo:** estamos haciendo un botón de like para c12z.io, para que aprendas bases de datos. Tú escribes lo de la base de datos; yo te doy la UI, el cableado de la ruta y los tests.

```

2. Conectar desde API   ✓ según el archivo, no está en este repo
3. Tabla likes          ← aquí
4. Insertar un like
5. Contar likes por post
6. Botón → API → DB
```

El paso 2 solo comprobaba que Postgres responde con `SELECT 1`. Ahora necesitas un sitio donde guardar datos.

**El problema:** alguien da like a `hola-mundo` y el contador pasa de 4 a 5. Recarga la página y vuelve a 4, porque el 5 solo vivía en memoria. Una base de datos vacía tampoco lo arregla: sin tabla, el `INSERT` falla con `relation "likes" does not exist`.

**La idea:** una tabla es una lista de filas con columnas fijas, y el esquema define esas columnas. Cada like es una fila:

```
post_id      created_at
hola-mundo   2026-11-04 10:00
hola-mundo   2026-11-04 10:05
otro-post    2026-11-04 10:07
```

Para saber cuántos likes tiene `hola-mundo`, Postgres cuenta sus filas: 2. Un clic más añade una fila y el total pasa a 3. Las filas siguen en Neon aunque recargues o reinicies la app.

**Por qué así:** lo obvio sería una columna `count` por post, a la que sumas 1 en cada clic. Es más simple y sirve si solo quieres el número. Pero solo guarda el total, así que nunca sabrás cuándo llegó cada like ni quién lo dio. Tampoco podrías impedir que alguien dé like dos veces. Con una fila por like, esa información se conserva.

**Qué nos da:** los pasos 4 y 5 tendrán dónde escribir y qué contar. Al terminar, esta comprobación debe mostrar tus columnas con su tipo:

```
psql "$DATABASE_URL" -c '\d likes'
```

Si no tienes `psql`, ejecuta en el SQL Editor de Neon una consulta a `information_schema.columns` filtrando por `table_name = 'likes'`.

**Cómo:**

```
[Botón] ──clic──▶ [API /likes] ──query──▶ [tabla likes en Neon]
   yo                  yo                      TÚ (este paso)
```

1. Decides las columnas: `post_id`, `created_at` y si hace falta `user_id`.
2. Eliges el tipo de cada una y si puede quedar vacía.
3. Escribes el `CREATE TABLE` y lo ejecutas en Neon.
4. Lo verificas con la comprobación de arriba.

Si quieres adelantarte, esto explica lo que vas a usar:
- [CREATE TABLE](https://www.postgresql.org/docs/current/sql-createtable.html)
- [Constraints: NOT NULL, UNIQUE, PRIMARY KEY](https://www.postgresql.org/docs/current/ddl-constraints.html)
- [Tipos de fecha y hora](https://www.postgresql.org/docs/current/datatype-datetime.html)
