```sql
-- Un like por fila: el total de un post se calcula contando sus filas.
CREATE TABLE likes (
  post_id    text        NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

## Cómo funciona

- **`post_id text`:** guarda valores como `hola-mundo`. Es texto porque tus posts se identifican así en nuestro ejemplo.
- **`created_at timestamptz`:** guarda el instante exacto del like, sin ambigüedad de zona horaria.
- **`NOT NULL`:** si falta el valor, Postgres rechaza la fila. Sin esto, un like sin post se guardaría y no contaría para ningún post.
- **`DEFAULT now()`:** si el `INSERT` no indica la hora, Postgres pone la actual. Así la API solo tiene que enviar `post_id`.

## Cómo conecta con el resto

- **Paso 4:** insertar un like solo necesitará `post_id`.
- **Paso 5:** contar las filas de un `post_id` dará el total.
- **Paso 6:** la API usará esas dos queries.

**Limitación:** la tabla no tiene clave primaria, es decir, una columna que identifique cada fila. Para contar no hace falta, pero sí para borrar un like concreto.

## Ejecútalo y compruébalo

Pega esto en el SQL Editor de Neon:

```sql
CREATE TABLE likes (
  post_id    text        NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);

INSERT INTO likes (post_id) VALUES ('prueba');

SELECT * FROM likes;
```

Deberías ver una fila con `prueba` y la hora actual en `created_at`. Si es así, borra la fila de prueba para que no cuente como like:

```sql
DELETE FROM likes WHERE post_id = 'prueba';
```
