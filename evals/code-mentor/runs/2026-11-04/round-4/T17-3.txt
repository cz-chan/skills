```sql
CREATE TABLE likes (
  post_id    text        NOT NULL,
  user_id    text        NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

## Por qué así

- **`CREATE TABLE likes (...)`:** crea la tabla, y cada línea de dentro define una columna con su nombre, tipo y reglas.
- **`text`:** guarda texto de cualquier longitud. Sirve para `hola-mundo` y para el ID del visitante sin tener que fijar un máximo.
- **`NOT NULL`:** hace que Postgres rechace la fila si falta ese valor. Así la regla está en la base de datos y se cumple aunque la API tenga un bug.
- **`timestamptz`:** guarda un instante exacto, sin depender de la zona horaria de quien da el like.
- **`DEFAULT now()`:** si el `INSERT` no trae `created_at`, Postgres pone la hora actual.
