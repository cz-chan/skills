## Qué necesitas saber
La forma general de crear una tabla es esta:

```
CREATE TABLE nombre (
  columna1 tipo opciones,
  columna2 tipo opciones
);
```

Las columnas van separadas por comas, sin coma tras la última, y el `;` cierra la instrucción.

**Piezas para tus columnas:**

| Pieza | Qué hace | Por qué la quieres |
|---|---|---|
| `text` | Tipo: texto de cualquier largo | Para `post_id`, como `hola-mundo` |
| `bigint` | Tipo: número entero grande | Para `id` |
| `timestamptz` | Tipo: fecha y hora con zona horaria | Para `created_at`; es el mismo instante esté donde esté el servidor |
| `GENERATED ALWAYS AS IDENTITY` | La DB numera cada fila: 1, 2, 3… | Tú nunca eliges el `id` |
| `PRIMARY KEY` | El valor es único e identifica la fila | Marca `id` como identificador |
| `NOT NULL` | Prohíbe dejar la columna vacía | Un like sin post no significa nada |
| `DEFAULT now()` | Si no envías valor, usa la hora actual | La DB rellena `created_at` |

## Qué debe pasar
Cuando en el paso 4 guardes un like enviando solo `post_id = 'hola-mundo'`:

| Columna | Valor | Quién lo pone |
|---|---|---|
| `id` | 1 | La DB numera |
| `post_id` | `hola-mundo` | Tú |
| `created_at` | 2026-11-04 10:00 | La DB usa la hora actual |

Si envías un like sin `post_id`, la DB lo rechaza con un error. Así no se guardan datos que luego no podrías contar.
