## Por qué hace falta una base de datos

Imagina que guardas el contador en una variable del servidor:

```ts
let likes = 0
```

| Acción | Valor de `likes` |
|---|---|
| Arranca el servidor | 0 |
| 3 clics | 3 |
| Recargas la página | 3 (el servidor sigue vivo) |
| Se reinicia el servidor | **0: se perdieron los likes** |

La variable vive en la memoria del proceso y desaparece con él. Una **base de datos** es otro programa que guarda los datos en disco, separado de tu app. Tu app se reinicia y los datos siguen allí.

**Postgres** es esa base de datos, y **Neon** te da un servidor Postgres en la nube, así que no tienes que instalar nada.

Para hablar con Postgres se usa **SQL**, un lenguaje con el que le pides cosas a la base de datos. Los datos se guardan en **tablas**: filas y columnas, con el tipo de dato de cada columna fijado. Por ejemplo, esta tabla no es de tu proyecto:

```
usuarios
 id | nombre
----+-------
  1 | Ana
  2 | Luis
```

## Paso 1: tu proyecto en Neon

La **connection string** es una URL con todo lo necesario para conectarse. Este ejemplo es inventado:

```
postgresql://ana:****@ep-ejemplo-123.eu-central-1.aws.neon.tech/neondb?sslmode=require
             │   │       │                                         │      │
          usuario │     host: la dirección del servidor       base de    conexión
              contraseña                                       datos     cifrada
```

Contiene tu contraseña: quien la tenga puede leer y borrar tus datos. Por eso va en `.env`, un archivo fuera de git que solo lee el servidor.

**Qué tienes que hacer:**

1. Entra en [console.neon.tech](https://console.neon.tech) y crea una cuenta, si no tienes.
2. Crea un proyecto, con la región más cercana a ti.
3. Pulsa **Connect** y copia la connection string. La interfaz puede haber cambiado un poco, porque esto lo escribo de memoria.
4. Crea un archivo `.env` en la raíz del proyecto con una sola línea, usando tu string real:
   ```
   DATABASE_URL=postgresql://...
   ```
5. Comprueba que está bien con este comando, que no muestra el secreto:
   ```sh
   grep -c '^DATABASE_URL=postgres' .env
   ```
   Debe imprimir `1`.

No pegues la string en el chat.
