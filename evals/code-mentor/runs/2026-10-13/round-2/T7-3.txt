El driver `@neondatabase/serverless` (ya está en `package.json`) te da `neon(url)`, que devuelve una función `sql`. Se usa como **tagged template**: escribes SQL entre backticks y `sql` lo envía a Neon. Devuelve un array de filas, cada fila es un objeto:

```ts
await sql`SELECT 1 AS ok`   // → [ { ok: 1 } ]
```

Qué escribir en `src/index.ts`:
1. Importa `neon` desde `@neondatabase/serverless`.
2. Crea `sql` con `neon(...)`, pasándole la URL de `process.env.DATABASE_URL`.
3. Añade la ruta `GET /api/db-check` que ejecute la query y devuelva las filas con `c.json(...)`.
4. Ojo: la query es asíncrona (va por red). ¿Qué necesita el handler para esperar su resultado?
