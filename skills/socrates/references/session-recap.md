# Session recap

Now you may state things directly. Use the user's own words where possible, in their language. Render it as normal Markdown (not inside a code block), following this structure. When showing it, translate the headings to the user's language; in the saved file keep them in English, exactly as below.

```markdown
# <Topic> — <YYYY-MM-DD>

## Conclusions you reached

- <one line per ladder step, in order; mark steps you were given with "(given)">

## Questions that got you there

1. <question> → <your answer, short>

## Thinking errors and how you fixed them

- **Assumed:** <wrong belief> → **Realized:** <what made it click>

## To explore next and why

- <the follow-up question>
- <optional: verified link> — <why it's worth reading now>
```

Include only questions that moved the user forward. Omit the errors section if there were none.

Links: only from the domain file's `## Resources`, ones the user gave you, or ones you opened and checked this session. Otherwise omit them — an invented URL destroys trust in the whole recap.

## Saving it

Save it as a session note — read [session-notes.md](session-notes.md) for where and format.
